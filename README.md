A beautiful landing page for a cosmetic brand that works perfectly on phones, tablets, and computers. It has product cards that zoom when you hover, a reviews section, a slideshow of products, and a newsletter signup form for updates, all styled with pretty colors. I used HTML, Tailwind CSS, and JavaScript to make it interactive. It scored 100% for speed and search engine ranking, 88% for ease of use on mobile (95% on desktop), and 93% for overall quality in testing.
